# 网页桌宠

`content/web-pet.js`（页面内物理与交互）+ `popup/pet-panel.js`（设置面板）。

> 2026-09-30 起**移除了 AI 聊天功能**（连带删掉 `content/lib/` 下约 630KB 的 katex / marked / 字体），只剩一个球：拖动、贴底散步、抛物线惯性、与鼠标尾迹碰撞反弹。迁移到 `markdown` / `LaTeX` 渲染需要重新引库。

## 交互

| 操作 | 行为 |
|---|---|
| 拖动 | 跟着指针走，松手时按拖拽轨迹估算初速度 |
| 松手（几乎没动） | 原地弹一下，进入 1.2 秒发呆 |
| 松手（有位移）且在空中 | 抛物线惯性下落，落地后贴底 |
| 松手（有位移）且在地面 | 恢复贴底散步 |
| 飞行/下落中碰到**圆点**尾迹 | 反弹（恢复系数见下） |
| 飞行/下落中碰到**带状**尾迹 | 按速度方向反弹或滑行 |
| 贴底散步时 | 不受尾迹影响 |
| 到达视口边缘 | 吸附 |

桌宠每次出现**强制贴在底部**（`py = groundY()`），不保留旧的垂直位置；只恢复水平位置。显隐与全部配置由 popup 控制。

## 物理参数

| 常量 | 值 | 含义 |
|---|---|---|
| `G` | 0.15 | 重力加速度（px/frame²，~60fps） |
| `PET_SIZE` | 56 | 显示尺寸 px |
| `MARGIN` | 8 | 与视口边缘最小间距 |
| `COLLISION_RADIUS` | `PET_SIZE/2 + 4` | 碰撞半径（减小避免穿模） |
| `COLLISION_COOLDOWN` | 6 | 碰撞冷却帧数，避免反弹瞬移 |
| `bounceCoef` | 用户可调 | 恢复系数 e |
| `throwCoef` | 用户可调 | 抛掷力度倍率 |

### 恢复系数 e（`webPetBounce`）

`storage.sync` 的 `webPetBounce`，范围 **0.2 ~ 1**，默认 **0.5**。0 = 不弹，1 = 完全弹性。

碰撞响应（圆点尾迹 `checkDotCollision`、带状尾迹 `checkRibbonCollision`）：

```js
v' = (v - 2(v·n)n) × e      // 沿法线做镜面反射，再乘恢复系数
```

撞视口边缘的反弹也走同一个 `e`，否则拖到边上手感与碰撞不一致。

**反弹速度上限随 e 缩放**：

```js
maxBounceVy() = -(3 + 15 × e)
```

不缩放的话，低弹性也会被固定上限「顶」住该落不落（速度被顶住、能量不衰减）。

| e | 速度上限 | 理论弹跳高度 |
|---|---|---|
| 0.2 | ≈ 6 px/frame | ≈ 120 px |
| 0.5（默认） | ≈ 10.5 | ≈ 368 px |
| 1.0 | 18 | ≈ 1080 px（比一屏还高）|

弹跳高度公式：`h = v² / (2G)`。

### 抛掷力度（`webPetThrow`）

`storage.sync` 的 `webPetThrow`，范围 **0.3 ~ 2**，默认 **1**（= 原始手感）。初速度与速度上限**一起**缩放：

```js
tVyMax = 8 × throwCoef;  tVxMax = 4 × throwCoef;
flyVy = clamp(flyVy × 0.6 × throwCoef, -tVyMax, tVyMax);
flyVx = clamp(flyVx × throwCoef,        -tVxMax, tVxMax);
```

上限不一起缩的话，滑块拉满也不会「抛得更远」。

### ⚠️ 历史坑：e > 1 等于给球加能量

早期版本是三个写死的常数：

```js
BOUNCE_DAMPING = 0.9;  BOUNCE_FORCE = 1.3;  MAX_BOUNCE_VY = -18;
```

`0.9 × 1.3 = 1.17 > 1` —— 每撞一次**反而多 17% 动能**，越弹越高；再叠加固定上限 `-18px/frame`，单次弹跳高度 `18²/(2×0.15) = 1080px`，比一屏还高。这就是「弹性系数太高、弹得太高」的成因，已在 V4.6.0 改为真正的恢复系数。

## 设置面板

- 开关与裁剪为草稿模式：改动只高亮「保存配置」按钮，不写 storage；点保存后写 `storage.sync`，content script 通过 `storage.onChanged` 立刻生效，**不用刷新页面**。
- 选图 / 清除图片仍立即生效（`storage.local` 的 `webPetImg`）。
- 圆形裁剪器：拖圆调位置、拖右下角小点缩放。popup 打开时若宠物视图不可见，容器宽度为 0 会让圆几何算成全 0（圆框钉在左上角、拖动被零尺寸钳死）——所以监听了 `ResizeObserver`，一旦可见就重算。

## 验证

用受控页（塞 `chrome.*` 最小 shim + 真实 `web-pet.js`）跑物理：

- **验证周期性行为必须采够时长/点数**。桌宠散步有随机停顿，1.6 秒窗口内位移为 0 会被误判成「功能坏了」；采 8 个点 / 5 秒以上才看清「走→停→走」。
- 拖动：派发 `pointerdown/move/up` 后位移应**恰好**等于给的 `dx`，拖拽中类名带 `xsdoi-pet-dragging`、松手变 `xsdoi-pet-flying`。
