## 写代码前先看

改 `content/board-beautify.js`（板块美化）之前**务必**读 [板块美化.md](板块美化.md) 的「压过站点样式的四条规律」和「液态玻璃禁忌」。那里面每一条都是实际踩出来的：改错一处会静默失效（CSS 规则不报错，只是不生效），或者直接把页面点坏（菜单点不动、按钮不悬浮、整页发白）。

## 术语

| 词 | 指什么 |
|---|---|
| 站点 | xsdoi.com，被扩展增强的那个 OJ |
| content script | 注入站点页面的脚本，在 `content/` 下 |
| 亚克力 | 三种玻璃外观之一：背景模糊 |
| 液态玻璃 | 三种玻璃外观之一：背景保持清晰，靠边缘折射 + 高光营造质感 |
| 玻璃层 | 半透明底色（亚克力 / 仅透明化模式下就是元素自身的 `background-color`；液态玻璃额外有 `::before` / `::after` 伪元素层） |
| 恢复系数 e | 网页桌宠碰撞反弹的物理系数，0 = 不弹、1 = 完全弹性 |
