# 常见问题

## 导入时提示「无法加载背景脚本」

这是 service worker 没起来。按可能性从高到低排查：

1. **有 `.js` 文件不是 UTF-8**（最常见）
   浏览器会拒绝加载并报 `无法为内容脚本加载"xxx.js"文件。该文件采用的不是 UTF-8 编码。`，但扩展卡片上只显示「无法加载背景脚本」，真实原因藏在**错误详情**里。
   → `edge://extensions` → 点扩展卡片上的**「错误」按钮**看原文。
   → 修法：删掉重新解压；或用编辑器时明确以 **UTF-8**（不是 ANSI/GBK）另存。
   → **跟系统有没有开「UTF-8 全球语言支持」无关**，详见 [构建与发布.md](构建与发布.md#️-扩展里的-js-必须是合法-utf-8)。

2. **缺文件**
   `background.js` 用 `importScripts('constants.js', 'idb.js')` 启动，**这两个文件缺一个就正好报「无法加载背景脚本」**。确认解压出来的文件夹里有 `constants.js` 和 `idb.js`。

3. **选错目录**
   「加载已解压的扩展程序」要选**含 `manifest.json` 的那一层**。从 GitHub 的 Code → Download ZIP 解压出来的是 `VibeCoding-WebExtensions-XSDOI-Plus-<短SHA>/`，别选到它的父目录。

4. **浏览器版本不够**
   最低 Chrome / Edge **102**（OPFS）。manifest 已声明 `minimum_chrome_version`，版本不够时会给友好提示。

## 装了但完全没效果

1. 先确认功能开关打开、且面板里点过「保存配置」（多数控件是草稿模式，改动不写 storage）。
2. 确认不是被 `.el-drawer` 抽屉排除（抽屉里整块排除美化）。
3. **站点改版导致选择器失效**：用探针对账选择器命中率 —— 在几个不同类型的页面（首页 / 详情页 / 列表页）各跑一次，**三个页面全都没命中的**基本可判定失效。清单里同时放新旧选择器做对照。
4. 常见改版模式：组件前缀被重命名、容器层级被拍平（`.lfe-body` 从子容器变成 `.lfe-body` 自身）。后者尤其阴险 —— 同一份 CSS 里用得最多的那条规则会静默整体失效。

## 亮色正常、暗色失效

大概率是**特异性打平 + 源码顺序决胜**：站点在 `html.theme-dark` 里重定义了同名 CSS 变量，扩展也用 `html.theme-dark`(0,1,1) → 同特异性，站点样式在后 → 站点赢。

对策：写 `html.theme-dark.theme-dark`(0,2,1)。

> **所以主题相关改动必须明暗两套都验**，只验亮色会漏掉一整类 bug。

---

## 某个按钮/链接悬停时没反应

扩展给基础类写了 `background-color: … !important`，而站点的 `:hover` 规则**没有** `!important` → 被压死。

对策：补一条更高特异性的 `:hover` / `:focus`，用半透明底色 + 提亮边框，**文字色别写**（让它继续跟随站点的品牌色）。

---

## 开关的选中态看不出区别

`!important` 会无差别压掉站点的状态色规则（`.is-checked` 这类无 `!important` 的规则），**与特异性无关**。

对策：把基础选择器收窄成 `:not(.状态类)`，让状态色交还给站点。

同理，**描边不要跟随状态色** —— 站点选中态的 `border-color` 往往与 `background` 同色，跟着写等于选中态又没有边框。

---

## 改完样式怎么确认真的生效了

不要只读 computed，也不要只肉眼看截图。完整流程见 [板块美化.md](板块美化.md#验证方法)，要点：

- 一个模式一个 HTML 文档，绝不能把多模式 CSS 堆同一页
- 受控复现页的**文档顺序**要还原生产：站点样式排在扩展样式之后
- 用 `vm` 跑真实脚本生成 CSS，别手抄
- 「看不看得见」要让**像素**说话（纯 Python 标准库解码 PNG，按亮度分桶）
- 探针别用 `headless --dump-dom`（本机 stdout 会被静默吞掉，0 字节、exit 0），走 CDP

## 桌宠相关

- **不出现**：确认 popup「网页桌宠」的「显示桌宠」已开**并保存过**。
- **弹得太高**：调「弹性系数」（恢复系数 e）到 0.2~0.4。默认 0.5 就是为此调的 —— 早期版本 e = 1.17 > 1，撞一次反而多 17% 动能。
- **抛得太远**：调「抛掷力度」，1 = 原始手感。
- **桌宠一直不动**：可能是随机发呆。散步有随机停顿，采样要够 5 秒 / 8 个点才看得出「走→停→走」。
